Setup Checklist

1. Create a Jenkins Pipeline job.

2. Add a Jenkinsfile to your GitHub repository.

3. Configure the job to use Pipeline script from SCM.

4. Add your repository URL and select the main branch.

5. Enable GitHub hook trigger for GITScm polling.

6. Configure a GitHub webhook pointing to your Jenkins server.

7. Push a commit and check the Jenkins build history.
